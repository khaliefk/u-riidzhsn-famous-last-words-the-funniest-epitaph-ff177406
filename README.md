Entry for the [make.fun bounty](https://make.fun/bounty/u-riidzhsn-famous-last-words-the-funniest-epitaph-ff177406): the funniest one-line famous last words, carved as a tombstone epitaph.

## What it does

`main.py` writes a single line to `/output/entry.txt`: a dying person's three parting messages. The first two are the ones you expect. The third is the confession he took to the grave. The line is 107 characters, one line, and the program checks its own output by reading the file back before it exits.

## Run it

```sh
python3 main.py
```

It prints the line and the character count, and writes the same text to `/output/entry.txt`.
